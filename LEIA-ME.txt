COROINHAS • v1.0.0 • NexoSites

1. Crie projeto NOVO em supabase.com.
2. SQL Editor → New query → cole todo schema.sql → Run.
3. Authentication → Providers → Email: habilitado. Mantenha confirmação de e-mail ativa (confira o e-mail enviado).
4. Project Settings → API → copie Project URL e chave PUBLISHABLE/ANON.
5. Abra config.js e substitua os 2 valores entre aspas. NUNCA use service_role nem secret key.
6. Envie index.html e config.js à RAIZ de seu repositório GitHub.
7. Settings → Pages → Deploy from branch → main / (root).
8. Abra o site e crie a conta que será coordenadora. Se necessário, confirme e-mail.
9. No Supabase SQL Editor execute (trocando o endereço pelo cadastro exato):
   update public.profiles set role='coordenadora',approved=true where email='EMAIL_DA_COORDENADORA';
10. Saia e entre novamente. Agora poderá aprovar outros usuários.

NOTAS DA VERSÃO
- Funciona como site web mobile. Avisos são internos e atualizados enquanto o app está aberto (consulta a cada 30 segundos). Push com app fechado e e-mail automatizado NÃO estão implementados.
- Exportação usa visualização de impressão do navegador: escolher 'Salvar como PDF'.
- A escala automática preenche somente vagas abertas de missas já cadastradas e compatíveis com regras fixas; não cria missas.
- Ao editar uma missa, as designações são recriadas; confirmações e motivos anteriores daquela missa se perdem. Evite editar escalas depois de iniciar o controle de presença nesta versão.
- A confirmação é liberada no dia da missa (fuso America/Sao_Paulo) e a falta é registrada pela coordenadora.
- Os pedidos de substituição são enviados à coordenadora e exigem aprovação.
- Atendimento técnico e foto: configure contato e URL pública HTTPS posteriormente.
- A página ainda não foi validada em navegador com um projeto Supabase real.
